## 🛡️ Architecture: Fraud/Trust Signal Swarm
Instead of a monolithic AI, we are building a **Hybrid Swarm** of specialized agents:

1. **Identity Agent**: Verifies legitimacy via local government databases (NIN/BVN) and RC numbers.
2. **Social Agent**: Scrapes reputation signals from Twitter/LinkedIn. If a 1-day-old account processes $50k, the Swarm flags it.
3. **Velocity Agent**: Monitors Solana/EVM transaction spikes to detect "pump and dump" payment spam or network attacks.
4. **Network Agent**: Analyzes on-chain "taint" (interactions with mixers or blacklisted wallets) via high-fidelity indexing.

### The Logic Engine (Trust Score)
Every transaction generates a **Signal Request**. The Swarm returns a **Merchant Trust Score (0-100)**:
- **Score < 40**: Transaction Blocked.
- **Score 40-70**: Held for 24-hour review / Tier 2 KYC upgrade required.
- **Score > 70**: Instant Payout / Settlement.
